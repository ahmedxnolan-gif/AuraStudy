# 🎓 AuraStudy - AI Personal Study Tutor

Welcome to **AuraStudy**! This web application acts as your personal AI tutor, helping you summarize study materials, generate comprehensive study guides, create interactive quizzes, and answer your follow-up academic questions using the **Gemini API**.

## 🔑 How to Use & Get Your API Key

To use AuraStudy, you need to provide your own **Gemini API Key** (it is free to generate):

1. **Get your API Key:**
   * Head over to [Google AI Studio](https://aistudio.google.com/).
   * Click on **Create API key** and copy your generated key.
2. **Setup on the Site:**
   * Open the [AuraStudy Live Link](https://ahmedxnolan-gif.github.io/AuraStudy/).
   * Paste your API key into the input field at the top.
   * Click **Save key** to securely store it in your browser's local storage.
3. **Start Studying:**
   * Choose your input method (Upload a **PDF** or **Paste text**).
   * Select your preferred output language.
   * Click **Create study guide** or switch to the **Quiz** mode to test your knowledge!
